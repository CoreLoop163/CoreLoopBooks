\section*{vector}
\addcontentsline{toc}{section}{vector}

vector是C++标准库为我们提供的类模板。可以将vector理解成保存同类型元素的一个不定长数组。使用vector需要包含相应的头文件及引入命名空间：
\begin{cppcode}
    #include <vector>
    using namespace std;    // vector、stack等定义在std命名空间（参考@\pageref{subsec:命名空间}页相关内容@）
\end{cppcode}


我们可以通过在尖括号中指定元素的类型，来定义不同类型的数组，如：
\begin{cppcode}
    vector<int> int_arr;        // 一个空的，容纳int型元素的不定长数组
    vector<char> char_arr;      // 一个空的，容纳char型元素的不定长数组
    vector<double> double_arr;  // 一个空的，容纳 double 型元素的不定长数组
    vector<vector<int> > vectorint_arr; // 容纳元素类型为 vector<int> 的不定长数组
\end{cppcode}

\minisection{返回vector中元素的数量}
可以通过\textbf{v.size()返回v中元素的数量}。

\minisection{访问vector中的元素}
vector中的元素下标从0开始，支持下标访问运算符：“[]”。可以通过\textbf{v[idx]返回v中第idx个位置上元素的引用}。注意：
\begin{enumerate}
    \item 由于返回的是引用，因此可以修改原数组中的元素，这一点和C语言原生数组类似；
    \item 下标访问只能访问v中已有元素。任何非法的下标访问（idx < 0 或 idx >= v.size() ）都是不安全的，将导致\term{未定义行为（Undefined Behavior，UB）}。
\end{enumerate}

\minisection{向vector对象中添加元素}
我们可以使用vector的成员函数\term{push\_back}向其中添加元素，如：
\begin{cppcode}
    vector<int> v;  // 空的vector对象，v
    for(int i=0; i<100; i++) {
        v.push_back(i); // 依次把整数值放到v的尾部
    }
    // 循环结束后v有100个元素，值分别为0到99
\end{cppcode}
注意：不能用下标形式添加元素。如：
\begin{cppcode}
    vector<int> v;
    for(int i=0; i<100; i++) {
        v[i] = i;
    }
\end{cppcode}
这段代码是绝对错误的。因为v是一个空的vector，根本不包含任何元素，所以不能通过下标去访问任何元素。正确的做法是使用push\_back。


\section*{引用}
\addcontentsline{toc}{section}{引用}
类似指针，\term{引用}也是一种复合类型，引用为对象起了另外一个名字，是某对象的一个别名。就像通过 “\*” 符号定义指针那样，可以通过“\&”符号来定义引用，如：
\begin{cppcode}
    int a = 5;      
    int* pa = &a;   // pa是指向a的指针
    int& ra = a;    // ra是a的一个别名
    cout << a << endl;  // 打印a，输出：5
\end{cppcode}
注意“\&”在C++中不仅有取地址的含义，在声明引用时，“\&”组成了声明符的一部分。就像“\*”既可以表示取指针变量指向的值，又可以作为声明符声明指针一样。

由于引用类型的对象只是另外某对象的一个别名，因此引用在定义时必须初始化。如：
\begin{cppcode}
    int& rb;    // 编译报错，引用必须被初始化
\end{cppcode}

定义了一个引用之后，对其进行的所有操作都是在与之绑定的对象上进行的：
\begin{cppcode}
    ra = 10;    // 把10赋值给ra所引用的对象，即赋值给a
    cout << a << endl;  // 输出：10
    cout << ra << endl; // 输出：10
\end{cppcode}
为引用赋值，实际上是把值赋给了与引用绑定的对象。获取引用的值，实际上是获取了与引用绑定的对象的值。甚至取引用对象的地址，取的都是引用对象所引用的那个对象的地址：
\begin{cppcode}
    cout << (&ra == &a) << endl;    // 输出：1
\end{cppcode}

\vspace{\baselineskip}

这也就是为什么\textbf{函数传参时，作为引用传参能够修改原变量的值}，类似指针一样：
\begin{cppcode}
    void ref(int& a) {
        a = 10;
    }
    void pointer(int* a) {
        *a = 20;
    }
    void value(int a) {
        a = 30;
    }
    int main() {
        int t = 5;
        
        ref(t);
        cout << t << endl;  // 输出：10
        
        pointer(&t);        
        cout << t << endl;  // 输出：20

        value(t);
        cout << t << endl;  // 输出：20

        return 0;
    }
\end{cppcode}

\section*{stack}
\addcontentsline{toc}{section}{stack}
类似vector，stack同样是C++标准库为我们提供的类模板，模板参数就是栈中存放的元素类型。使用stack需要include相应头文件及引入命名空间：
\begin{cppcode}
    #include <stack>
    using namespace std;
\end{cppcode}

通过指定模板参数，我们就可以定义存放不同类型元素的栈。如：
\begin{cppcode}
    stack<int> is;  // 存放int的栈
    stack<int> ds;  // 存放double的栈
\end{cppcode}
甚至：
\begin{cppcode}
    stack<vector<int> > vis;    // 存放不定长数组的栈
\end{cppcode}

栈s的一些常用操作如下：
\begin{enumerate}[label=\arabic*）]
    \item s.push(e);    // 将值为e的元素入栈
    \item int t = s.top();      // 返回s的栈顶元素的引用（但不弹出该元素），将其值拷贝给t
    \item s.pop();      // 弹出栈顶元素
    \item s.empty();    // 若栈s为空，此处返回值为true，否则返回false。
    \item s.size();     // 返回栈s中元素的数量
\end{enumerate}

注意，使用top()操作和pop()操作时，一定要保证栈是非空的，否则将导致\term{未定义行为（Undefined Behavior，UB）}。


\section*{queue}
\addcontentsline{toc}{section}{queue}
类似vector和stack，queue同样是C++标准库为我们提供的类模板，模板参数就是队列中存放的元素类型。使用queue需要include相应头文件及引入命名空间：
\begin{cppcode}
    #include <queue>
    using namespace std;
\end{cppcode}

通过指定模板参数，我们就可以定义存放不同类型元素的队列。如：
\begin{cppcode}
    queue<int> iq;  // 存放int的队列
    queue<int> dq;  // 存放double的队列
\end{cppcode}
甚至：
\begin{cppcode}
    queue<vector<int> > viq;    // 存放不定长数组的队列
\end{cppcode}

队列q的一些常用操作如下：
\begin{enumerate}[label=\arabic*）]
    \item q.push(e);    // 将值为e的元素入队
    \item int t = q.front();      // 返回q的队首元素的引用（但不将该元素出队），将其值拷贝给t
    \item q.pop();      // 将队首元素出队
    \item q.empty();    // 若队列q为空，此处返回值为true，否则返回false。
    \item q.size();     // 返回队列q中元素的数量
\end{enumerate}

注意，使用front()操作和pop()操作时，一定要保证队列是非空的，否则将导致\term{未定义行为（Undefined Behavior，UB）}。

\section*{C++的Hello, World}
\phantomsection
\addcontentsline{toc}{section}{C++的Hello, World}
\label{sec:cpp-hello-world}
一个入门C语言的源文件，假设叫他“helloworld.c”，大概长这样：
\begin{cppcode}
    #include <stdio.h>
    
    int main() {
        printf("Hello, World!\n");
        return 0;
    }
\end{cppcode}

而C++源文件的名字通常以cpp为后缀，和C语言很相似，一个“helloworld.cpp”大概长这样：
\begin{cppcode}
    #include <iostream>

    using namespace std;
    int main() {
        cout << "Hello, World!" << endl;
        return 0;
    }
\end{cppcode}

我们逐一将上面的代码拆解。

\subsection*{iostream与cin、cout}
与C类似，
\begin{cppcode}
    #include <iostream>
\end{cppcode}
是引入iostream这个头文件。iostream是C++标准库提供的标准输入输出流，其中有两个最为常用的功能：cin 和 cout。

正如它们的名字in和out那样，cin用于从标准输入流读（in）数据，而cout用于将数据输出（out）到标准输出流。来看一个简单的例子：
\begin{cppcode}
    int a, b;
    cout << "请输入两个数字：";
    cin >> a >> b;
    cout << "它们的和是：" << a + b << endl;  
\end{cppcode}

在C++中，cin 和 cout 是“流对象”，符号“<<”和“>>”生动地表达了数据的流向。cout的原理（简单理解）如下图所示：

进一步理解，事实上“<<”与“>>”都是二元运算符，其左侧操作对象是cout或cin，右侧对象是要读入或输出的数据，而该运算的返回值，事实上就是操作后的相应流对象（cin或cout）。
比如cin >> a >> b; cin >> a 执行完成后，返回值即是新的cin对象（此时流中还剩" 5"的数据），于是cin >> a >> b 相当于先将3读入a，之后再执行cin >> b，只不过

    char c = 'a';
    string d = "hello, world";

    cout << d << endl;  // 输出："hello, world\n"

\end{cppcode}


\subsection*{namespace---命名空间}
\label{subsec:命名空间}
接下来来看这段代码：
\begin{cppcode}
    using namespace std;
\end{cppcode}
这行代码的作用是：使用标准库命名空间 std。这样我们在使用 C++ 标准库中的名称时，就可以省略前面的 std::。
例如，在前面的代码中：
\begin{cppcode}
    cout << "请输入两个数字：";
    cin >> a >> b;
\end{cppcode}
实际上cin和cout都属于std这一\term{命名空间}。如果没有写 using namespace std;，我们就需要这样写：
\begin{cppcode}
    std::cout << "请输入两个数字：";
    std::cin >> a >> b;
\end{cppcode}

using namespace std; 并不是 C++ 程序必须写的一行代码。即使不写它，只要使用 std::cout、std::endl 这样的完整名称，程序依然可以正常运行。

事实上，vector、stack、queue以及绝大多数标准库的重要工具都是定义在std命名空间的。如：std::stack<int>, std::queue<int> 等。
从工程实践来看，using namespace std; 可能引入名称冲突，因此通常不建议在大型项目的头文件中使用。
但对于以学习为目的的编程者，使用它可以减少代码中的额外符号，让读者更容易把注意力放在程序本身。\\

顺带说一个很有意思的事：事实上任何合法的C代码，一定是合法的C++代码，并且C风格的字符串char*是可以直接打印到cout的。比如：

        char tmp[10] = "world!";
        cout << tmp << endl;
    }
    
\end{cppcode}

\section*{为结构体定义比较规则、std::sort()的使用}
\phantomsection
\addcontentsline{toc}{section}{为结构体定义比较规则、std::sort()的使用}
\label{sec:为结构体定义比较规则、std::sort()的使用}

\subsection*{为结构体定义比较规则、std::sort()的使用}

对于自定义结构体（类），我们可以使用C++提供的\term{运算符重载}功能来自定义结构体对象之间的大小比较规则。
如以下代码：
\begin{cppcode}
    struct Player {
        string name;
        long long id;
        double score;   

        bool operator < (const Player other) {
            return this->score < other.score;
        }
    };
\end{cppcode}
其中
\begin{cppcode}
    bool operator < (const Player other) {
        return this->score < other.score;
    }
\end{cppcode}
是Player这个结构体（类）的一个成员函数（看起来可能会有点奇怪，但这确确实实是一个名为“operator <”的函数）
，该函数定义了Player结构体的“<”运算符规则，或者说，定义了“<”这个二元运算符作用于两个Player对象时的规则。this指针表示调用
该函数的对象指针，是<运算符的左操作数，而右操作数作为函数参数（other）被传递进来。
具体来说，对于如下代码：
\begin{cppcode}
    Player p1; p1.score = 3.1;
    Player p2; p2.score = 3.2;
\end{cppcode}
当我们调用
\begin{cppcode}
    p1 < p2;
\end{cppcode}
时，相当于以p1为<运算符的左操作数，p2为右操作数调用函数“operator <”，于是该函数的返回值为
\begin{cppcode}
    p1.score < p2.score; // 3.1 < 3.2成立，返回true。
\end{cppcode}

这样就实现了通过“<”运算符对两个Player对象的大小比较功能。

\minisection{std::sort()的使用}
标准库<algorithm>中为我们提供了一个函数：sort()，它定义在std命名空间中，作用是对数组或容器进行排序。

但sort()要求数组或容器的元素类型支持“<”运算符（
事实上这种说法不严谨，但对于初学者来说可以简单这么理解）。如：
\begin{cppcode}
    #include <algorithm>
    #include <iostream>
    #include <vector>

    int main() {
        int a[5] = {2,3,1,4,5};
        vector<int> va = {2,4,5,1,3};
        std::sort(a, a+4);  // 对a的前4个元素排序，若写(a, a+5)就是对数组a的全部5个元素排序
        std::sort(va.begin(), va.end());    // 对va的所有元素排序

        for(int i=0; i<5; i++) {
            cout << a[i];
        }   // 输出：12345
        for(int i=0; i<5; i++) {
            cout << va[i];
        }   // 输出：12345
    }
\end{cppcode}

若Player类重载了<运算符，则sort函数可以按照比较规则对Player对象排序：
\begin{cppcode}
    struct Player {
        // ...

        bool operator < (const Player other) {
            return this->score < other.score;
        }
    };

    Player players[10]; // 假设存储了10个player
    std::sort(players, players+10); // 将这些player按score从小到大排序
\end{cppcode}

若某个类不支持<运算符，对该类的数组或容器调用sort函数将导致编译报错。

\subsection*{重载运算符}
当各种运算符（如+, -, <）等，作用于内置类型时，它的语义是由C++标准定义的，如：
\begin{cppcode}
    int a, b;
    a + b;
    a - b;  
    a < b;
\end{cppcode}
它们的作用非常明确。事实上，如果我们将一些运算符作用于自定义类型，将导致编译报错，如：
\begin{cppcode}
    struct Player {
        string name;
        long long id;
        double score;   
    };
    Player p1, p2;
    p1 + p2;    // 编译报错
    p1 - p2;    // 编译报错
\end{cppcode}
但是，C++提供了一种叫做\term{重载运算符}的机制，允许我们为自定义类型来定义各种运算符的作用。定义一个重载的运算符与定义一个函数非常相似，语法如下：
\begin{cppcode}
    <返回类型> operator <你要重载的运算符> (函数参数列表) {
        // 函数体
    }
\end{cppcode}

其中“operator”是关键字。可以看到，这与正常的函数定义：
\begin{cppcode}
    <返回类型> <函数名>                   (函数参数列表) {
        // 函数体
    }
\end{cppcode}
几乎一模一样，可以说：重载运算符就是函数名为“operator xxx”的一个函数。重载运算符可以被定义为\term{成员函数}和\term{非成员函数}。当定义为成员函数时，
C++规定运算符的第一个运算对象就是调用该函数的对象（this）。运算符的返回值其实就是函数的返回值。

比如，你还可以为Player对象定义+、-等运算符：
\begin{cppcode}
    struct Player {
        string name;
        long long id;
        double score;   

        Player operator + (const Player& other) {
            Player p;
            p.score = this->score + other.score;
            return p;
        }

        Player operator - (const Player& other) {
            Player p;
            p.score = this->score - other.score;
            return p;
        }
    };
    Player p1; p1.score = 3.1;
    Player p2; p2.score = 3.2;
    Player p3;
\end{cppcode}
以上就为Player定义了两个名字是“operator +”和“operator -”的成员函数。于是你便可以像调用普通函数一样调用它们：
\begin{cppcode}
    /* 你可能不相信，这行代码是绝对合法的。就是在调用p1对象的名为“operator +”的函数，函数参数是p2.*/
    p3 = p1.operator +(p2); 
    // 上面这行代码可以简写为：
    p3 = p1 + p2;
\end{cppcode}
C++允许我们重载各种一元和二元运算符，如\textquotedbl ++\textquotedbl， \textquotedbl --\textquotedbl， 
\textquotedbl *\textquotedbl， \textquotedbl !\textquotedbl， 甚至 \textquotedbl ()\textquotedbl（函数调用运算符）等。
感兴趣的同学可以参考C++相关资料。
